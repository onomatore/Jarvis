# Jarvis
ИИ-агент для дискорда, телеги


# Необходимо создать файл .env, который будет содержать следующее:
TELEGRAM_BOT_TOKEN=
DISCORD_BOT_TOKEN=
OPENROUTER_API_KEY=

Также необходимо применить requirements.txt

Так, как библиотека дискорда voice_recive поломана, то необходимо заменить файл opus.py, на представленный в репозитории, для корректной работы бота. Иначе будет ошибка opus.

## Что может
Пока умеет отвечать на сообщения из дискорда и телеги, также можно командой !join добавить в голосовой чат дискорда, и он может ответить на вопрос заданный текстом голосом. 
Сейчас он также может один раз ответить на голосой ввод, но потом ломается. (починю позже)
